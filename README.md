# Khaadi E-Commerce Website

A full-stack e-commerce website inspired by Khaadi, built as a final project.

## Features

- Responsive homepage
- Product listing
- Product details
- Shopping cart
- Checkout
- Order placement
- Admin orders page
- MongoDB database
- REST API
- Responsive mobile design

## Technologies Used

### Frontend
- React.js
- React Router
- CSS

### Backend
- Node.js
- Express.js
- Mongoose

### Database
- MongoDB Atlas

### Deployment
- Vercel — Frontend
- Railway — Backend

## Project Structure

- khaadi-ecommerce — React Frontend
- backend — Node.js + Express Backend
